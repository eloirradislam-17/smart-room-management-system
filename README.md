# Smart Room Management System

Plateforme IoT intelligente pour la gestion multi-salles.

## Technologies

- ESP32
- C++ / Arduino
- MQTT
- Node.js / Express
- React
- MongoDB
- Git / GitHub

## Objectifs

- Surveillance de la température et de l'humidité.
- Gestion intelligente des salles.
- Commande à distance des équipements.
- Gestion des utilisateurs ADMIN et USER.
- Alertes et historique des mesures.
